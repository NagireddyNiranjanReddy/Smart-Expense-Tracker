# 💰 Smart Expense Tracker

A simple and smart web-based expense tracking application built using **Python, Flask, SQLite, HTML, CSS, and JavaScript**. It helps users manage their income and expenses, monitor monthly budgets, and understand their spending habits.

## 🚀 Features

- 📊 **Dashboard:** View total income, expenses, and remaining balance.
- 💸 **Transaction Management:** Add and delete income and expense transactions.
- 🏷️ **Categories:** Organize transactions by category.
- 📅 **Monthly Filtering:** View transactions for a selected month.
- 🔍 **Search Transactions:** Quickly find specific transactions.
- 📈 **Expense Visualization:** View spending patterns through category charts.
- 🎯 **Budget Management:** Set monthly budgets for different categories.
- ⚠️ **Budget Alerts:** Get alerts when spending approaches the budget limit.
- 📥 **CSV Export:** Download transaction records as a CSV file.
- 🗄️ **SQLite Database:** Store transaction and budget information locally.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/NagireddyNiranjanReddy/Smart-Expense-Tracker.git
```

### 2. Navigate to the Project Folder

```bash
cd Smart-Expense-Tracker
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

**macOS / Linux:**

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

### 7. Open in Your Browser

Visit:

```text
http://127.0.0.1:5000
```

Your Smart Expense Tracker application is now running!
